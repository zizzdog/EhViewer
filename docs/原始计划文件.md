# EhViewer 下载结构平铺与集中式缩略图管理改造计划

## 一、 需求目标

1. **下载根目录平铺**：漫画打包为 `[gid]-[标题].cbz` 直接存放于下载根目录，不保留画廊同名子目录。
2. **后处理原子移动**：下载与 `archiveTo()` 过程保持原生逻辑，在 `postArchive()` 阶段通过 `atomicMove` 移动并重命名至根目录，随后删除临时目录。
3. **缩略图集中管理**：封面统一保存在 `downloadLocation/thumb/[gid].[format]`，内置 `.nomedia` 文件以阻断媒体扫描。
4. **在线阅读降级**：本地 CBZ 文件被移除后，阅读器检测文件缺失自动降级为网络在线加载（`useEhPageLoader`），下载列表仍可借助缓存或网络正常展示缩略图。

---

## 二、 技术决策

| 项目 | 方案 | 依据 |
| :--- | :--- | :--- |
| **打包策略** | `postArchive` 阶段原子移动 | 原生打包逻辑完全不变，仅在完成后通过文件系统原子移动（Linux `rename` 系统调用）移至根目录，避免侵入 JNI 归档流程 |
| **文件名长度** | 复用 `FileUtils.sanitizeFilename` | 该方法强制截断文件名至 200 字节以内（UTF-8），加上 `.cbz` 扩展名后约 204 字节，满足 Linux 255 字节限制 |
| **缩略图路径** | `downloadLocation/thumb` | 集中存放，解除与画廊子目录的绑定 |
| **媒体扫描隔离** | `thumb/` 内置独立 `.nomedia` | 根目录媒体扫描开关被开启导致根目录 `.nomedia` 移除时，`thumb/` 仍能独立保持不被相册扫描 |
| **在线回退** | `DownloadInfo.archiveFile` 返回空 | 寻址优先匹配根目录平铺 CBZ，缺失时返回 `null`，自动触发 `ReaderScreen` 的在线加载逻辑 |

---

## 三、 修改文件清单

| 文件 | 修改内容 |
| :--- | :--- |
| `SpiderDen.kt` | `postArchive()` 中执行 CBZ 原子移动、抽取缩略图并删除临时目录；`exportAsCbz()` 优先读根目录 CBZ |
| `DownloadManager.kt` | 声明 `downloadThumbLocation`；`archiveFile` 优先寻址根目录平铺 CBZ；`deleteDownload` 同步清理根目录 CBZ 与缩略图 |
| `DownloadThumbInterceptor.kt` | 缩略图优先读 `downloadThumbLocation`，兼容旧目录迁移，未命中走网络并回写缓存 |
| `CommonOperations.kt` | `confirmRemoveDownloadRange` 同步清理平铺 CBZ 与缩略图；`keepNoMediaFileStatus` 维护 `thumb/.nomedia` |

---

## 四、 实施步骤

1. **基础设施**：在 `DownloadManager.kt` 中声明 `downloadThumbLocation`（自动生成 `.nomedia`），改造 `archiveFile` 寻址与删除清理逻辑；在 `CommonOperations.kt` 同步适配。
2. **后处理移动**：在 `SpiderDen.kt` 的 `postArchive()` 中增加 `cbzFile moveTo targetCbz`、封面另存与临时文件夹删除。
3. **拦截器适配**：在 `DownloadThumbInterceptor.kt` 中将缩略图路径切换为 `downloadThumbLocation`，保留网络回写机制。
