# EhViewer 改造开发进展

## 核心实现记录

### 提交哈希：`5b91bba2c`
**修改类型**：`feat(download): flatten CBZ into download root via post-processing and unify thumbnails`

#### 涉及文件及改动
1. **`app/src/main/kotlin/com/hippo/ehviewer/spider/SpiderDen.kt`**
   - 保持 `archive()` 及 `archiveTo()` 原生打包流程不变。
   - `postArchive()` 中：
     - 使用 `atomicMove` 将生成于画廊子目录下的 `[gid].cbz` 移动并重命名至 `downloadLocation / "${info.downloadDirname()}.cbz"`。
     - 调用 `saveThumbToUnifiedLocation()` 将封面图复制至 `downloadLocation/thumb/[gid].[format]`。
     - 调用 `dir.delete()` 递归删除画廊临时子目录。
   - `exportAsCbz()` 优先寻址根目录下平铺的 CBZ 文件。

2. **`app/src/main/kotlin/com/hippo/ehviewer/download/DownloadManager.kt`**
   - 声明 `downloadThumbLocation` 全局路径（`downloadLocation / "thumb"`），不存在时自动创建目录与 `.nomedia`。
   - 改造 `DownloadInfo.archiveFile`：优先返回 `downloadLocation / "$dirname.cbz"`，文件不存在时返回 `null`（触发在线降级阅读）。
   - `deleteDownload()` 中补充清理根目录平铺 CBZ 与 `thumb/` 目录下对应的缩略图。

3. **`app/src/main/kotlin/com/hippo/ehviewer/coil/DownloadThumbInterceptor.kt`**
   - 缩略图路径重定向至 `downloadThumbLocation / "${info.gid}.$format"`。
   - 保留旧画廊子目录封面迁移逻辑。
   - 本地未命中时放行走 Coil 网络请求，成功后回写写入 `downloadThumbLocation`。

4. **`app/src/main/kotlin/com/hippo/ehviewer/ui/CommonOperations.kt`**
   - `confirmRemoveDownloadRange()` 补充清理根目录平铺 CBZ 与对应缩略图。
   - `keepNoMediaFileStatus()` 确保 `downloadThumbLocation` 内的 `.nomedia` 常驻。

---

## 关键技术点备忘

1. **文件名长度安全性**：`info.downloadDirname()` 内部调用 `FileUtils.sanitizeFilename`，强制截断至 200 字节（UTF-8），加上 `.cbz` 后共约 204 字节，满足 Linux 255 字节限制。
2. **后处理原子移动**：由于源文件与目标文件在同一挂载点，`atomicMove` 为内核级 `rename` 操作，耗时 <1ms，不产生二次 I/O。
3. **独立 `.nomedia` 屏障**：在 `thumb/` 内部独立常驻 `.nomedia`，避免根目录媒体扫描开关变更导致封面图片流入系统相册。
