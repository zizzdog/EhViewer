# EhViewer 改造开发进展

## 核心实现记录

### 提交哈希：`5b91bba2c`
**修改类型**：`feat(download): flatten CBZ into download root via post-processing and unify thumbnails`

#### 涉及文件及改动
1. **`app/src/main/kotlin/com/hippo/ehviewer/spider/SpiderDen.kt`**
   - 保持 `archive()` 及 `archiveTo()` 原生打包流程不变。
   - `postArchive()` 中：
     - 使用 `atomicMove` 将生成于画廊子目录下的 `[gid].cbz` 移动并重命名至 `downloadLocation / "${info.downloadDirname()}.cbz"`。
     - 调用 `saveThumbToUnifiedLocation()` 将封面图复制至 `downloadLocation/thumb/[gid].[format]`。
     - 调用 `dir.delete()` 递归删除画廊临时子目录。
   - `exportAsCbz()` 优先寻址根目录下平铺的 CBZ 文件。

2. **`app/src/main/kotlin/com/hippo/ehviewer/download/DownloadManager.kt`**
   - 声明 `downloadThumbLocation` 全局路径，不存在时自动创建目录。
   - 改造 `DownloadInfo.archiveFile`：优先返回 `downloadLocation / "$dirname.cbz"`，文件不存在时返回 `null`（触发在线降级阅读）。
   - `deleteDownload()` 中补充清理根目录平铺 CBZ 与缩略图。

3. **`app/src/main/kotlin/com/hippo/ehviewer/coil/DownloadThumbInterceptor.kt`**
   - 缩略图路径重定向至 `downloadThumbLocation / "${info.gid}.$format"`。
   - 保留旧画廊子目录封面迁移逻辑。
   - 本地未命中时放行走 Coil 网络请求，成功后回写写入 `downloadThumbLocation`。

4. **`app/src/main/kotlin/com/hippo/ehviewer/ui/CommonOperations.kt`**
   - `confirmRemoveDownloadRange()` 补充清理平铺 CBZ 与对应缩略图。

### 提交哈希：`934ee8a47`
**修改类型**：`fix(download): resolve Spotless import order and SAF permission deadlock on download location`

#### 涉及文件及改动
1. **`app/src/main/kotlin/com/hippo/ehviewer/ui/CommonOperations.kt`**
   - 修正 import 排序，将 `com.ehviewer.core.files.list` 置于 `com.ehviewer.core.files.*` 块中，严格遵循字母升序，消除 Spotless/ktlint 报错。
   - 恢复 `keepNoMediaFileStatus` 原生逻辑，彻底移除对 `downloadThumbLocation` 的副作用调用，解决路径变更时的 SAF 权限撤销导致 `SecurityException`（“无法获取下载路径”）死锁 Bug。

2. **`app/src/main/kotlin/com/hippo/ehviewer/download/DownloadManager.kt`**
   - 将 `downloadThumbLocation` 重定向为 `appCtx.cacheDir.toOkioPath() / "download_thumbs"`。
   - 缩略图移入应用内部私有缓存，能够被 Android 系统“设置 $\rightarrow$ 应用 $\rightarrow$ 清除缓存”一键释放，且彻底切断对外部公共存储目录的依赖与媒体扫描污染。
   - 规范 import 排序并移除未使用的引用。

### 提交哈希：`d0fac400b`
**修改类型**：`fix(download): save images to downloadDir and write CBZ directly to root`

#### 涉及文件及改动
1. **`app/src/main/kotlin/com/hippo/ehviewer/spider/SpiderDen.kt`**
   - 将 `imageDir` 固定为 `downloadDir`，下载期间单页临时碎图直接存放在用户设定的下载目录下（`downloadLocation/dirname`），彻底解除内部缓存目录占用。
   - `archive()` 中直接将目标 CBZ 句柄创建在外层下载根目录（`downloadLocation / "$dirname.cbz"`），由 SAF `createDocument` 原生创建，彻底规避 Android SAF `renameDocument` 无法跨目录移动导致的 CBZ 随临时文件夹被误删的问题。
   - `postArchive()` 中在检测到根目录 CBZ 存在后，执行缩略图抽取并安全删除画廊临时子文件夹。
