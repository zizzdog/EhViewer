# EhViewer 改造开发进展

## 核心实现记录

### 提交哈希：`5b91bba2c`
**修改类型**：`feat(download): flatten CBZ into download root via post-processing and unify thumbnails`

#### 涉及文件及改动
1. **`app/src/main/kotlin/com/hippo/ehviewer/spider/SpiderDen.kt`**
   - 保持 `archive()` 及 `archiveTo()` 原生打包流程不变。
   - `postArchive()` 中：
     - 使用 `atomicMove` 将生成于画廊子目录下的 `[gid].cbz` 移动并重命名至 `downloadLocation / "${info.downloadDirname()}.cbz"`。
     - 调用 `saveThumbToUnifiedLocation()` 将封面图复制至 `downloadLocation/thumb/[gid].[format]`。
     - 调用 `dir.delete()` 递归删除画廊临时子目录。
   - `exportAsCbz()` 优先寻址根目录下平铺的 CBZ 文件。

2. **`app/src/main/kotlin/com/hippo/ehviewer/download/DownloadManager.kt`**
   - 声明 `downloadThumbLocation` 全局路径，不存在时自动创建目录。
   - 改造 `DownloadInfo.archiveFile`：优先返回 `downloadLocation / "$dirname.cbz"`，文件不存在时返回 `null`（触发在线降级阅读）。
   - `deleteDownload()` 中补充清理根目录平铺 CBZ 与缩略图。

3. **`app/src/main/kotlin/com/hippo/ehviewer/coil/DownloadThumbInterceptor.kt`**
   - 缩略图路径重定向至 `downloadThumbLocation / "${info.gid}.$format"`。
   - 保留旧画廊子目录封面迁移逻辑。
   - 本地未命中时放行走 Coil 网络请求，成功后回写写入 `downloadThumbLocation`。

4. **`app/src/main/kotlin/com/hippo/ehviewer/ui/CommonOperations.kt`**
   - `confirmRemoveDownloadRange()` 补充清理平铺 CBZ 与对应缩略图。

### 提交哈希：`942d4d3cd`
**修改类型**：`feat(metadata): standardize ComicInfo.xml for LANraragi with tag translation support`

#### 涉及文件及改动
1. **`app/src/main/kotlin/com/hippo/ehviewer/spider/ComicInfo.kt`**
   - 结构重构以完美适配 LANraragi `ComicInfo.pm` 插件：
     - 补全 `<Title>` 节点，解决 LANraragi 无法获取标题被动回退文件名的问题；
     - `<Writer>` 映射纯社团名，供 LRR 自动附加 `group:` 前缀；
     - `<Penciller>` 映射纯画师名，供 LRR 自动附加 `artist:` 前缀；
     - `<Characters>` 映射纯角色名，供 LRR 自动附加 `character:` 前缀；
     - `<Genre>` 仅输出纯净画廊大分类（如 `Doujinshi` / `同人志`），彻底根除微标签对媒体库流派分类的严重污染；
     - 新增标准 `<Tags>` 节点存放带命名空间的微标签集，直通 LRR tags 数据库；
     - 彻底废除将原作塞入 `<Teams>` 的错误逻辑，`<Series>` 和 `<Teams>` 保持为空；
   - 双阶段严格标签翻译机制：
     - 阶段一：在未翻译状态下通过 raw 英文命名空间精准提取分类到 `rawArtists`、`rawGroups`、`rawCharacters`、`rawTags`；
     - 阶段二：联动 `Settings.showTagTranslations`，开启时对画师、社团、角色、大分类及微标签（`命名空间:标签名`，如 `女性:女仆`、`原作:xxx`）进行精准中文化替换；未开启时输出原始英文。
   - 在 `<Tags>` 中附带未翻译的原生纯小写 `uploader:ABCD` 与 `timestamp:1694353678` 标签。

### 提交哈希：`de5d1d177`
**修改类型**：`fix: restore LanguageISO ISO 639-1 code, consolidate deleteLocalFiles, and fix coroutine cancellation`

#### 涉及文件及改动
1. **`app/src/main/kotlin/com/hippo/ehviewer/spider/ComicInfo.kt`**
   - `LanguageISO` 严格还原为标准 ISO 639-1 两字母小写码（`simpleLanguage?.lowercase()`，如 `zh`、`ja`、`en`），杜绝生成非法标签污染 LRR 标签库与破坏 `ComicInfo.xsd` 规范；
   - 语言微标签（如 `language:chinese`）恢复标准归入 `<Tags>`（支持联动中文化为 `语言:中文`），LRR 解析 `<Tags>` 时原样追加，语法完全合规。

2. **`app/src/main/kotlin/com/hippo/ehviewer/download/DownloadManager.kt`**
   - 抽取统一下载文件清理扩展方法 `DownloadInfo.deleteLocalFiles()`，清除 `DownloadManager` 与 `CommonOperations` 中的多处重复硬编码与遗漏死角；
   - `archiveFile` 寻址移除多余的 `.isFile` 再次探测，改用单次 `find`，降低热路径开销。

3. **`app/src/main/kotlin/com/hippo/ehviewer/ui/CommonOperations.kt`**
   - `confirmRemoveDownloadRange` 改调 `info.deleteLocalFiles()`，移除多余未使用的导包。

4. **`app/src/main/kotlin/com/hippo/ehviewer/spider/SpiderDen.kt`**
   - `saveThumbToUnifiedLocation()` 将 `runCatching` 替换为 `runSuspendCatching`，确保正常向外抛出协程 `CancellationException`，维护结构化并发安全。
