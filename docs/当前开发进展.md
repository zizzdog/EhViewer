## 三、 缩略图缓存与 `dirname` 解耦

### `fix(coil): cache download thumbnails without a dirname` — 封面缓存不再依赖 `DOWNLOAD_DIRNAME`
**背景**：只导入数据库备份（或更换过下载目录）时，`DOWNLOAD_DIRNAME` 表为空 ⇒ `DownloadInfo.dirname` 为 `null` ⇒ 拦截器入口守卫 `!info.dirname.isNullOrBlank()` 失败 ⇒ 整段逻辑被跳过，网络取到的封面**永远不会落盘**，只能依赖 Coil 自身缓存与网络。

**`coil/DownloadThumbInterceptor.kt`**
- 入口守卫由 `info != null && !info.dirname.isNullOrBlank()` 放宽为 `info != null`；`dirname` 改为只服务于 legacy 分支；
- legacy 回退改为 `info.dirname?.takeIf { it.isNotBlank() }?.let { downloadLocation / it }`，去掉原有的 `!!` 强制解包；
- 效果：`dirname` 为空的条目同样会查 `cacheDir/download_thumbs/[gid].[format]`，未命中则联网取图并**落盘缓存**，同时回写 `GALLERIES.THUMB`；
- `dirname` 非空的条目行为完全不变，无回归。

**同时确立的取舍**：`archiveFile` 仍依赖 `dirname`，`dirname` 为空时返回 `null`、阅读走联网降级。这是接受的行为（源文件本就不在设备上），本次不做改动。

## 四、 数据安全

### `c1fc425f2` — 打包完整性校验（删除源图前的唯一屏障）
**背景**：JNI `archiveFdBatch()`（`app/src/main/cpp/archive.c:478-484`）不检查 `archive_write_header` / `archive_write_data` / `archive_write_finish_entry` 的返回值。因此“CBZ 文件存在”不等于“CBZ 内容完整”。而 `postArchive()` 只以“根目录 CBZ 是否存在”判定成功——写入中途失败时会以损坏 CBZ 替换掉全部源图，且原图不可恢复。

**`spider/SpiderDen.kt`**
- `archive()` 在 `archiveTo()` 之后、返回之前新增 `verifyFlatCbz()` 校验：
  - CBZ 确实被创建（`isFile`）；
  - 文件非空（`metadataOrNull().size > 0`）；
  - 能被 `ZipFile` 打开并遍历条目（捕获中央目录损坏 / 文件被截断）；
  - 全部 `00000001.jpg … 00000N.jpg` 页条目与 `ComicInfo.xml` 均存在。
- 校验只在真实文件系统路径上执行；`content://` 路径退化为仅检查文件大小，避免在不支持的路径上抛异常。
- 校验失败 → 抛异常 → 被**原有的** `.onFailure` 捕获 → 删除损坏 CBZ → 返回失败 → `postArchive()` 找不到 CBZ → 不执行目录删除，**源图全部保留**，条目停留在 `STATE_FAILED` 可重试。
- 同时补齐 `runSuspendCatching` 缺失的 import（修复编译失败），并清除 `deleteLocalFiles()` 收敛后遗留的 3 处未使用 import。

**同时确认的上游既有行为（非本项目引入，按“不改上游”原则不处理）**
- `postArchive()` 的 `archived` 判据仅为“文件存在”，内容完整性由 `c1fc425f2` 的校验兜住；
- `FileNameRegex` 在改为整目录删除后成为上游遗留死代码。

## 六、 构建约束备忘

- 本仓库为 **SHA-1** 对象格式。文中的哈希取自 `git log --oneline` 的显示形式（当前为 9 位，由 Git 按仓库规模自动缩放，非显式设置 `core.abbrev`）。
- Spotless（ktlint）通过 `build-logic` 的 convention plugin 应用于 `app` 与各 library 模块，CI 执行 `./gradlew spotlessCheck`。
- `.editorconfig` 仅禁用 `class-signature`、`mixed-condition-operators` 两条标准规则，未启用 ktlint 实验规则集。
